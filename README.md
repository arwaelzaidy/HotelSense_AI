 HotelSense - Smart Hospitality AI

HotelSense is an AI-powered smart assistant designed for the hospitality industry. It helps hotel guests get instant, accurate answers to their questions using Natural Language Processing (NLP).

---

 Key Features
 Semantic Search: Understands the meaning of guest questions beyond exact keywords.
  Smart & Safe:  Uses a confidence threshold (0.6) to avoid wrong answers.
  Fast Response: Responds in less than 0.1 seconds.
  Easy UI: Interactive interface built with Gradio.

---

Tech Stack
Language: Python
 NLP Model: `Sentence-Transformers` (`all-MiniLM-L6-v2`)
  Similarity Metric:  `Cosine Similarity`
  Libraries: PyTorch, Pandas, Gradio
